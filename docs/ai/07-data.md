# 7. Дані: на чому вчити

**Модель — це стиснені дані.** Вона знає лише те, що бачила, і говорить так,
як писали в її корпусі. Якість даних важить більше, ніж архітектура.

## Скільки треба

| Мета | Обсяг тексту | Приклад |
|------|--------------|---------|
| Перевірити, що код працює | 10–100 КБ | `data/corpus.txt` у цьому репо |
| Іграшка, що пише «схоже на мову» | 1–10 МБ | кілька книжок, казки |
| Маленька, але зв'язна модель | 100 МБ – 1 ГБ | україномовна Вікіпедія |
| Справжня LLM | трильйони токенів | веб-краули (Common Crawl, FineWeb) |

Емпіричне правило (Chinchilla): **~20 токенів даних на 1 параметр моделі**.
Для моделі на 1 млн параметрів це ~20 млн токенів.

## Де брати (українською)

- Вікіпедія: дампи `dumps.wikimedia.org` (ukwiki).
- Відкриті книжки: класика в суспільному надбанні (Франко, Шевченко, Леся Українка…).
- Датасети на Hugging Face: шукати за фільтром мови `uk` (наприклад, багатомовні частини FineWeb-2, CulturaX).
- Свої тексти: нотатки, документація, листування, тобто те, в чому модель має бути «експертом».

Перевіряйте ліцензію: для особистого навчання майже все ок, для публікації моделі — не завжди.

## Підготовка (pipeline)

```
сирі файли → очистка → дедуплікація → фільтр якості → токенізація → train/val → бінарний файл
```

1. **Очистка**: прибрати HTML, меню, рекламу, зламане кодування, зайві пробіли.
2. **Нормалізація**: один тип лапок і апострофа (`'` vs `’` vs `ʼ` дають різні токени!).
3. **Дедуплікація**: однакові абзаци змушують модель зазубрювати. Прибрати дублікати (хешами).
4. **Фільтр якості**: відкинути надто короткі тексти, спам, тексти іншою мовою.
5. **Токенізація** один раз → масив id → зберегти як `Uint16Array` у файл.
   Навчання читає готові числа і не токенізує текст на кожному кроці.
6. **Розділення** 90% train / 10% val (див. [05-training.md](05-training.md)).

## Дані для чату

Для чат-асистента потрібен ще один, маленький, але якісний набір діалогів
«питання → хороша відповідь» (тисячі прикладів, не мільярди). Про це в [08-assistant.md](08-assistant.md).

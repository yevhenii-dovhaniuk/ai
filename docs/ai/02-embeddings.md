# 2. Ембедінги: число → зміст

Id токена (наприклад, `4021`) — це просто номер, у ньому немає змісту.
Ембедінг перетворює номер на **вектор**, наприклад зі 128 чисел, який описує, що цей токен «означає».

## Як це працює

Таблиця ембедінгів — це матриця `[розмір_словника × d_model]`.
Ембедінг токена — це просто рядок цієї таблиці з номером токена:

```ts
const embedding: number[][] = randomMatrix(vocabSize, dModel); // спершу випадкові числа
const vec = embedding[tokenId];                               // і все, це "lookup"
```

Спершу числа випадкові. Під час навчання вони зсуваються так, що токени,
які трапляються в схожих контекстах, отримують схожі вектори:

```
"кіт"   → [0.8, 0.1, -0.3, ...]
"пес"   → [0.7, 0.2, -0.2, ...]   ← поруч із "кіт"
"банк"  → [-0.5, 0.9, 0.4, ...]   ← далеко
```

Знаменитий приклад: `король − чоловік + жінка ≈ королева`.
Напрямки у просторі ембедінгів кодують зміст (рід, число, тему…).

## Позиція

Attention (наступний розділ) не знає порядку слів: «кіт з'їв мишу» і «мишу з'їв кіт»
для нього однакові набори. Тому до вектора токена додають **інформацію про позицію**.

| Спосіб | Ідея | Де |
|--------|------|----|
| Навчувані позиційні ембедінги | Ще одна таблиця `[max_context × d_model]`, де рядок = позиція | GPT-2. Найпростіше, з цього й почнемо |
| Синусоїдальні | Фіксовані хвилі різних частот | Оригінальний Transformer (2017) |
| **RoPE** | «Повертаємо» вектори на кут, що залежить від позиції | Llama, Qwen та більшість сучасних моделей |

```ts
// вхід у трансформер для токена на позиції pos:
const x = add(tokenEmbedding[tokenId], positionEmbedding[pos]);
```

## Розмір d_model

Довжина вектора — головний «регулятор» розміру моделі:
- наша іграшкова модель: 64–128;
- GPT-2 small: 768;
- великі моделі: 4096–16384.

Більший вектор може вмістити більше змісту, але дає більше ваг і довші обчислення.

## Вихід: зворотний шлях

Наприкінці моделі треба перетворити вектор назад на оцінку для кожного токена.
Для цього вектор множать на матрицю `[d_model × vocab]` і отримують **logits**.
Часто для цього використовують ту саму таблицю ембедінгів, транспоновану
(**weight tying**). Так менше ваг і краща якість.

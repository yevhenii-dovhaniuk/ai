# Як влаштована LLM: карта

LLM (Large Language Model) робить одну-єдину річ:
**дивиться на текст і вгадує наступний шматочок тексту**. Це все.
Чат, переклад, код і «міркування» з'являються тому, що цю дію повторюють багато разів.

```
 "Київ — столиця"
        │
        ▼
 ┌──────────────┐  1. Токенізація: текст → числа
 │  Tokenizer   │     "Київ", " —", " столиця" → [1834, 12, 9921]
 └──────┬───────┘
        ▼
 ┌──────────────┐  2. Ембедінги: число → вектор (список чисел зі «змістом»)
 │  Embeddings  │     1834 → [0.12, -0.80, 0.33, ...]
 └──────┬───────┘
        ▼
 ┌──────────────┐  3–4. Трансформер: N однакових блоків.
 │ Transformer  │       Кожен блок: Attention («на що дивитись»)
 │   × N        │                 + MLP («що з цим робити»)
 └──────┬───────┘
        ▼
 ┌──────────────┐  Вихідний шар: вектор → оцінка для КОЖНОГО токена словника
 │   Logits     │  (logits), а softmax перетворює оцінки на ймовірності
 └──────┬───────┘
        ▼
 ┌──────────────┐  6. Генерація: вибираємо токен (" України"), дописуємо
 │   Sampling   │     його в кінець і повторюємо все спочатку
 └──────────────┘
```

Де модель бере знання: **5. Навчання**. Їй дають мільярди речень і
підкручують її числа (ваги), поки вгадування не стане добрим.

## Словник одним рядком

- **Токен** — шматок тексту (слово, частина слова, символ), який модель бачить як одне ціле.
- **Словник (vocab)** — усі токени, які знає модель. Кожен має свій номер (id).
- **Вектор** — список чисел. Ним модель описує «зміст».
- **Вага (параметр)** — одне число всередині моделі, яке підбирають під час навчання. У GPT-3 їх 175 млрд.
- **Logits** — сирі оцінки «наскільки підходить кожен токен».
- **Softmax** — перетворює logits на ймовірності, які в сумі дають 1.
- **Loss** — число, яке показує, наскільки модель помилилась. Навчання намагається його зменшити.
- **Градієнт** — підказка, в який бік крутити кожну вагу, щоб loss зменшився.
- **Контекст** — скільки токенів модель бачить одночасно.
- **Інференс** — використання вже навченої моделі (на противагу навчанню).

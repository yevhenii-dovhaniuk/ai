# 1. Токенізація: текст → числа

Нейромережа працює лише з числами. Токенізатор ріже текст на шматочки (токени)
і дає кожному номер.

```
"Привіт, світ"  →  ["При", "віт", ",", " світ"]  →  [512, 88, 11, 4021]
```

Також він уміє зворотне: `decode([512, 88, 11, 4021]) → "Привіт, світ"`.

## Три способи різати

| Спосіб | Приклад | Словник | Плюси | Мінуси |
|--------|---------|---------|-------|--------|
| По символах | `П`,`р`,`и`,`в`… | ~100–200 | Дуже просто, немає невідомих слів | Довгі послідовності, модель мусить сама вчити слова |
| По словах | `Привіт`, `світ` | сотні тисяч | Короткі послідовності | Величезний словник, нові слова невідомі |
| **Підслова (BPE)** | `При`,`віт` | 30k–200k | Золота середина | Трохи складніше |

Усі сучасні LLM використовують **підслова**, найчастіше алгоритм **BPE** (Byte Pair Encoding).

## BPE за 4 кроки

1. Починаємо зі словника з окремих байтів (256 штук), тож будь-який текст можна закодувати.
2. Шукаємо в корпусі пару сусідніх токенів, яка трапляється найчастіше, наприклад `"с" + "т"`.
3. Додаємо в словник новий токен `"ст"` і замінюємо всі такі пари в тексті.
4. Повторюємо, поки словник не досягне потрібного розміру (наприклад, 8000).

```ts
// серце BPE: знайти найчастішу пару
function mostFrequentPair(ids: number[]): [number, number] | null {
  const counts = new Map<string, number>();
  for (let i = 0; i < ids.length - 1; i++) {
    const key = `${ids[i]},${ids[i + 1]}`;
    counts.set(key, (counts.get(key) ?? 0) + 1);
  }
  let best: string | null = null;
  for (const [k, c] of counts) if (best === null || c > counts.get(best)!) best = k;
  return best ? (best.split(",").map(Number) as [number, number]) : null;
}
```

Результат навчання токенізатора — **список злиттів (merges)** у порядку їх додавання.
Кодування нового тексту повторює ці злиття в тому ж порядку.

## Спеціальні токени

Службові «слова», яких немає у звичайному тексті:
- `<|bos|>` / `<|eos|>` — початок / кінець тексту (модель вчиться вчасно зупинятись);
- `<|user|>`, `<|assistant|>` — хто говорить у чаті (див. [08-assistant.md](08-assistant.md));
- `<|pad|>` — заповнювач, щоб вирівняти довжини в батчі.

## Що важливо знати

- Модель **не бачить букв**, лише токени. Тому LLM погано рахує літери в слові.
- Українська «дорожча» за англійську: те саме речення займає більше токенів,
  якщо токенізатор вчили переважно на англійському тексті. Свій токенізатор
  на українському корпусі цю проблему знімає.
- Токенізатор навчають **окремо і до** навчання моделі. Потім його вже не змінюють.

# 0. Мінімум математики

Щоб написати LLM, вистачить п'яти ідей. Усе інше складається з них.

## Вектор

Список чисел: `[0.2, -1.0, 3.5]`. Його можна уявляти як точку або стрілку в просторі.
Дві схожі речі мають схожі вектори, тобто їхні точки лежать поруч.

```ts
type Vector = number[];
```

**Скалярний добуток (dot product)** показує, наскільки два вектори «дивляться в один бік»:

```ts
const dot = (a: Vector, b: Vector) => a.reduce((s, x, i) => s + x * b[i], 0);
// великий плюс → схожі, ~0 → не пов'язані, мінус → протилежні
```

На цьому побудована вся увага (attention).

## Матриця

Таблиця чисел, тобто масив векторів. Множення вектора на матрицю означає **перетворення**:
вектор розміру `n` перетворюється на вектор розміру `m`.

```ts
type Matrix = number[][]; // [n][m]
function matVec(x: Vector, W: Matrix): Vector {
  const out = new Array(W[0].length).fill(0);
  for (let i = 0; i < x.length; i++)
    for (let j = 0; j < out.length; j++) out[j] += x[i] * W[i][j];
  return out;
}
```

Майже всі ваги LLM — це матриці. Майже весь час роботи йде на множення матриць,
тому й потрібні GPU: вони множать тисячі чисел паралельно.

## Нелінійність (активація)

Якщо просто множити матриці одну за одною, результат буде еквівалентний **одній** матриці.
Щоб модель могла вивчати складні речі, між множеннями ставлять просту нелінійну функцію:

```ts
const relu = (x: number) => Math.max(0, x);              // найпростіша
const gelu = (x: number) =>                               // використовують у GPT
  0.5 * x * (1 + Math.tanh(Math.sqrt(2 / Math.PI) * (x + 0.044715 * x ** 3)));
```

## Softmax

Перетворює будь-які числа на ймовірності: усі стають додатними, а сума дорівнює 1.
Чим більше число, тим більша ймовірність.

```ts
function softmax(xs: number[]): number[] {
  const max = Math.max(...xs);                 // віднімаємо max, щоб exp не переповнився
  const exps = xs.map((x) => Math.exp(x - max));
  const sum = exps.reduce((a, b) => a + b, 0);
  return exps.map((e) => e / sum);
}
softmax([2, 1, 0]); // ≈ [0.67, 0.24, 0.09]
```

## Похідна і градієнт

Похідна показує, **як зміниться результат, якщо трохи змінити вхід**.
Градієнт — це похідні по всіх вагах одразу.

Навчання зводиться до циклу:
1. порахувати помилку (loss);
2. порахувати градієнт, тобто в який бік змінити кожну вагу, щоб помилка зменшилась;
3. трохи зсунути кожну вагу в цей бік;
4. повторити мільйони разів.

Рахувати градієнти вручну не потрібно. Для цього є **autograd**: кожна операція
(`+`, `*`, `exp`…) запам'ятовує, як рахувати свою похідну, а потім ланцюжок
проходять у зворотному порядку (**backpropagation**). Це ~150 рядків коду,
і ми напишемо його самі (див. [11-roadmap.md](11-roadmap.md)).

## Логарифм

`log` перетворює множення на додавання і робить маленькі ймовірності зручними числами:
`log(0.001) ≈ -6.9`. Loss в LLM дорівнює `-log(ймовірність правильного токена)`:
- модель впевнено права (p = 0.99) → loss ≈ 0.01;
- модель помилилась (p = 0.01) → loss ≈ 4.6.

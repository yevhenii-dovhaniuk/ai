# 9. Навколо моделі: з LLM робимо «ШІ»

LLM — це «мозок», але сам по собі він обмежений: знає лише те, що бачив при навчанні,
не має пам'яті між розмовами і нічого не може зробити у світі.
Сучасний «ШІ» — це LLM плюс програмна обв'язка.

```
          ┌──────────── Застосунок (наш сервер) ────────────┐
 юзер ──► │  пам'ять ─► промпт ─► LLM ─► відповідь           │ ──► юзер
          │     ▲          ▲        │                        │
          │     │       RAG-пошук   └─► виклик інструменту ──┼──► API, файли, код
          │     └──────────────────────── результат ◄────────┘
          └──────────────────────────────────────────────────┘
```

## 1. Промпт-інжиніринг

Найдешевший спосіб змінити поведінку — змінити текст на вході:
system prompt, приклади («few-shot»), чіткий формат відповіді.

## 2. RAG (Retrieval-Augmented Generation): знання з документів

Модель не знає ваших документів. RAG знаходить потрібні шматки і вставляє їх у промпт.

1. Документи ріжуть на шматки (~500 токенів).
2. Кожен шматок перетворюють на вектор моделлю ембедінгів ([02-embeddings.md](02-embeddings.md), та сама ідея).
3. Вектори кладуть у **векторну базу** (або навіть просто в масив).
4. Питання користувача → вектор → шукаємо найближчі шматки (cosine similarity).
5. Промпт: «Використай ці фрагменти: … Питання: …».

```ts
const cosine = (a: Vector, b: Vector) => dot(a, b) / (norm(a) * norm(b));
```

Плюси: знання оновлюються без перенавчання, а модель може посилатись на джерело.

## 3. Інструменти (tool / function calling)

Модель вчать писати не лише текст, а й структурований виклик:

```json
{ "tool": "get_weather", "args": { "city": "Київ" } }
```

Сервер бачить цей виклик, сам виконує функцію, повертає результат у промпт,
і модель продовжує з реальними даними. Так LLM рахує (калькулятор), шукає в інтернеті,
читає файли, керує розумним домом.

## 4. Агенти

Агент — це **цикл**: модель думає, викликає інструмент, дивиться на результат і вирішує,
що далі, поки задача не виконана.

```ts
while (!done) {
  const step = await llm(history);
  if (step.toolCall) history.push(await runTool(step.toolCall));
  else done = true;
}
```

## 5. Пам'ять

- **Короткочасна**: історія поточного чату в промпті (обмежена контекстом).
- **Довготривала**: важливі факти зберігаються в базі й підтягуються через RAG у нові розмови.
- **Стиснення**: стару частину розмови модель сама підсумовує коротким текстом.

## 6. Мультимодальність

Картинки, звук, відео теж перетворюють на «токени» (шматочки зображення → вектори),
і той самий трансформер обробляє їх разом із текстом.

## 7. Безпека та обмеження

- **Галюцинації**: модель упевнено вигадує. RAG і посилання на джерела зменшують це.
- **Prompt injection**: текст із документа чи сайту може містити «інструкції» для моделі.
  Інструменти з побічними ефектами потребують підтвердження людиною.
- **Доступ**: наш сервер у інтернеті, тому токен доступу й ліміт запитів обов'язкові (див. `docs/infra.md`).
